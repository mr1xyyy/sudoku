# Sudoku (React + Vite + TypeScript)

Веб-приложение судоку с двумя режимами:
- `Классический` - игра с таймером, ошибками и выбором сложности.
- `Решатель` - ввод своей сетки и автоматическое решение.

## Возможности
- Переключение языков: `RUS / ENG / UZB`.
- Светлая и тёмная темы.
- Выбор сложности: `Лёгкий`, `Средний`, `Сложный`, `Экспертный`.
- Подсветка строки, столбца и блока выбранной клетки.
- Проверка конфликтов (одинаковые числа в строке/столбце/блоке).
- История ходов (`Отменить`), очистка клетки и всей сетки.
- Поддержка ввода:
  - через UI-кнопки `1..9`
  - через клавиатуру (`1..9`, `Backspace/Delete/0`, стрелки).
- Локализованные сообщения об ошибках для всех языков.
- Адаптация под desktop / tablet / phone.

## Технологии
- `React 19`
- `TypeScript`
- `Vite`
- `Tailwind CSS`
- `lucide-react` (иконки)

## Запуск проекта
Требуется `Node.js` (рекомендуется LTS).

1. Установить зависимости:
```bash
npm install
```

2. Запустить в dev-режиме:
```bash
npm run dev
```

3. Сборка production:
```bash
npm run build
```

4. Локальный предпросмотр сборки:
```bash
npm run preview
```

## Скрипты
- `npm run dev` - запуск dev-сервера Vite.
- `npm run typecheck` - проверка типов TypeScript без сборки.
- `npm run build` - typecheck + production build.
- `npm run preview` - предпросмотр production-сборки.

## Кратко по архитектуре
- `sudoku_app.tsx` - контейнер приложения: состояние, обработчики, переключение режимов, таймер, модальные окна.
- `components/*` - UI-слой (шапка, поле, панель управления, кнопки).
- `logic/sudoku.ts` - бизнес-логика:
  - генерация новой игры
  - проверка валидности
  - поиск конфликтов
  - решение судоку (backtracking).
- `constants/translations.ts` - все тексты интерфейса и ошибок.
- `types/sudoku.ts` - общие типы данных.
